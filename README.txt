SRIJITA & ARNAB — WEDDING INVITATION
=====================================

This folder is self-contained and intended for GitHub Pages or local testing.

Files:
  index.html
  style.css
  script.js
  assets/          48 image assets
  start-local.bat  opens the site in your browser
  README.txt

INVITATION MODES
----------------

Both Biye + Bou Bhat:
  index.html?invite=both

Biye only:
  index.html?invite=biye

Bou Bhat only:
  index.html?invite=boubhat

HASH EXAMPLES
-------------

Correct:
  index.html?invite=biye#rsvp
  index.html?invite=both#story
  index.html?invite=boubhat#reception

Incorrect:
  index.html#rsvp?invite=biye

LOCAL
-----

Double-click index.html to test.

For better local testing, run start-local.bat.
It will start a tiny local web server if Python is installed.

GITHUB PAGES
------------

Upload the entire folder contents to a GitHub repository.
Enable GitHub Pages from the repository's Settings > Pages.

IMPORTANT
---------

Bou Bhat time was not provided, so no time has been invented.
RSVP is demo-only and is stored in the current browser's localStorage.
